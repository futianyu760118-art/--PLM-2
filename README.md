> 以 **物料料号 PartNo** 为全局唯一主键，打通新品立项、结构设计、模具开发、试模量产、图纸管控全链路的企业级 PLM 系统。

## AEOS 研发自治中心 V0.2 对齐（迭代分支）

本仓正在按 `AEOS研发自治中心 V0.2 / PLM-2 V1.1` 归档基线增量升级，原则是**不重写PLM-2**，而把它作为 AEOS 研发自治中心的 Engineering Kernel。

本轮已进入代码的核心改造：

- 19个研发节点保持现有业务定义，7个关键节点增加 `RD_LEAD → GM` 双级审批。
- 关键节点不得再通过直接写 `DONE` 绕过审批。
- 项目健康分升级到 `AEOS-RD-HS-V0.2`：CF使用正式项目变更，CR使用必填字段完整率。
- 节点Evidence同步登记统一 `Evidence_ID`，为 Evidence360 / 审计 / Agent 调用提供基础。
- 新增 Gate Namespace，区分 `DEV-G0~G6`、`RD-MG1~MG5` 与待G2冻结的 `PLM-G0~G8`。
- 新增 Metric Object 治理字段及研发Action Center数据底座。
- Agent自治边界仍保持 L0 查询 / L1 分析 / L2 建议，未授权L3+。

实施说明见：[docs/aeos-rd-center-v0.2-implementation-baseline.md](docs/aeos-rd-center-v0.2-implementation-baseline.md)。

> 注意：PLM-G0~G8正式映射、真实指标阈值及研发主管/总经理角色映射仍属于G2待冻结项；本轮不会把候选规则冒充正式生产制度。

## 三、快速启动

### 1. 启动数据库

```bash
docker-compose up -d
```

数据库会在首次启动时自动执行 `database/` 下的建表与种子数据脚本。

### 2. 启动主后端 (plm-backend)

```bash
cd plm-backend
mvn spring-boot:run
```

访问 Swagger 文档: http://localhost:8080/api/doc.html

### 3. 启动算法服务 (plm-algorithm)

```bash
cd plm-algorithm
pip install -r requirements.txt
python -m app.main
```

### 4. 启动前端 (plm-frontend)

```bash
cd plm-frontend
npm install
npm run dev
```

访问: http://localhost:5173

## 五、已实现功能 (八大底座 + 3D子系统 + 模具全生命周期)

### 模块1 物料主数据 (全局唯一主键 PartNo)
- 料号全局唯一校验，重复自动拦截
- 自动编号 (HJ+yyyyMMdd+0001)
- 物料状态流转: 草稿 → 评审中 → 正式发布 → 量产在用 / 变更中 / 作废 / 封存
- **发布后基础信息锁定，修改必须走 ECN 变更**
- 物料创建时**自动生成 17 层固定档案目录树**

### 模块2 ECN 工程变更 (三级审批心脏)
- 固定审批流: **工程师提交 → 研发主管一审 → 供应链总监二审 → 生效**
- 完整状态机: 草稿/待一审/待二审/通过/驳回/已生效/已作废
- **ECN 生效后自动升级物料版本号** (V1.0 → V1.1)
- **旧版文件自动作废 + 加盖水印 + 锁定只读 + 禁止下载** (模块8生命周期联动)
- 驳回可修改重提，全流程流转日志留痕 (时间线展示)

### 模块3 BOM 多级爆炸 (3D 联动核心)
- 无限级树形结构，支持自定义层级
- **循环引用自动检测** (防止 BOM 死循环)
- 子件级联删除 (含全部下级子件)
- 版本管理、关联 ECN

### 模块4 IQC/IPQC 品质检验标准
- 六大检验分类: 尺寸/外观/装配/功能/防水结构/来料
- 检验项目绑定料号 + 图纸版本 + 3D位置
- 图纸版本更新时提示同步更新标准
- 作废版本检验标准灰化封存

### 模块5 外协发图审批流 (防泄密核心)
- 外协账号**无主动下载权限**，只能通过审批链接下载
- 审批通过自动生成**不可逆水印 + 有效期(7/15/30天)**
- 过期文件彻底失效无法打开
- **所有外协下载记录全留痕** (操作人/IP/时间)

### 模块6 RBAC 四级角色权限体系
- 固定六大角色，权限矩阵写死
- 页面/按钮/文件/预览/下载/外网 六维管控
- 角色权限树形分配，用户管理 + 密码重置

### 模块7 文件安全 & 日志溯源引擎
- **@OperationLog AOP 注解全留痕** (上传/删除/修改/预览/下载/导出/审批/ECN)
- 日志含: 操作人/账号/IP/设备/操作内容/关联料号/文件版本/耗时
- 内外网文件物理隔离存储 (intranet/extranet 双目录)
- 显性水印 + 隐形溯源水印 (账号+时间+IP)

### 模块8 档案全生命周期管理
- 17 层固定目录树自动生成 (关闭自定义目录创建)
- 完整生命周期: 新建草稿 → 内部评审 → 正式发布 → 变更迭代 → 作废 → 封存归档
- 正式版文件禁止覆盖，只能版本迭代
- **所有档案禁止物理删除**，只能作废/封存

### 3D 子系统 (模块A/B/D)
- 3D 模型库: 外观/结构/模流/模具拆模/爆炸图
- 内网存高精度原始文件，外网自动脱敏 GLB
- Three.js 在线预览引擎 (预留 360°旋转/缩放/聚焦)
- AI 建模对接: Meshy / Tripo3D (Python 算法服务)
- 3D 爆炸解析生成初级 BOM 数据

### 模具全生命周期 (模块G/H/I)
- 模具固定资产台账: 编号/料号/模腔/啤数/资产价值/状态全生命周期
- 试模修模履历: 时间线展示，永久留存
- 注塑成型 SOP 工艺卡: 料温/模温/射压/缩水补偿等全套参数

### 工序自动化流转 (V1.1)
- 工序路线绑定业务对象 (项目/模具/物料/ECN)，按顺序编排工序步骤
- **上一道工序完成 → 自动激活下一道并向其负责人推送待办** (plm_work_item, 含 SLA 时限)
- 待办完成可反向联动工序流转，支持跳过(留痕)、取消路线、全程操作日志
- 末道工序完成自动闭环路线 (COMPLETED)，发布领域事件 (PROCESS_STEP_PUSHED / PROCESS_ROUTE_COMPLETED)

### 全模块数据导入 / 导出 / 自检 (注册表驱动)
- 统一 `dataio` 引擎，覆盖 11 个业务模块 (物料/BOM/ECN/模具/品质/外协/项目/立项/工序/3D/待办)
- **导出/模板**: EasyExcel xlsx，中文表头 + 独立「填写说明」Sheet(必填/枚举候选/关联引用)
- **导入**: 按模板表头智能映射字段，逐行校验(必填/类型/枚举/唯一/关联/日期先后)，支持「预检」与正式导入，输出逐行错误报告
- **自检**: 字段完整率 + 必填/唯一/枚举/类型/关联/日期规则扫描，输出健康分与问题清单
- 前端每个模块页面内置「数据导入 / 导出 / 模板 / 自检」工具栏

## 八、关键设计决策

1. **全局唯一主键 PartNo**: 所有数据挂载料号下，全库唯一索引
2. **BOM 物化路径 (ltree)**: PostgreSQL 原生扩展加速树形查询
3. **ECN 强管控**: 无 ECN 审批 = 版本不生效，生效后旧版文件自动作废+水印锁定
4. **17层固定目录树**: 物料创建自动生成，禁止自定义，保证归档规范统一
5. **软删除 + 版本快照**: 档案永久可追溯，禁止物理删除
6. **JWT 无状态认证**: 前后端分离，便于多端接入
7. **算法微服务独立**: Python 处理 3D 图形算力，Java 专注业务
8. **内外网物理隔离**: 文件存储分 intranet/extranet 双目录，外网零模具数据
9. **AOP 操作日志**: 注解式全留痕，SpEL 动态提取料号/版本
10. **水印双模式**: 显性水印(企业+外协+有效期) + 隐形溯源(PDF元数据/图片像素)
11. **统一外部对接规范**: `ExternalSystemService` 接口, ERP/MES/CRM 统一适配
12. **分享链接零鉴权**: 外网公开预览, Token 校验 + 时效 + 访问次数限制
