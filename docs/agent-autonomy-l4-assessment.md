# 智能体自治等级 L0–L4 评估（AEOS autonomy_level）

> 文档编号: HJ-PLM-AGENT-L4-ASSESS-v1.0
> 依据: AEOS V1.1 智能体体系（autonomy_level / Guard / Evidence）+ DEH 闭环
> 脚本: `scripts/test-agent-l4.ps1`
> 结论: **当前无智能体达到 L4**；质检官/总控达到 L2（只读执行 + 生成待决策动作），其余 L0–L1

---

## 一、L0–L4 等级标准

| 等级 | 名称 | 能力要求 | 人审 |
|------|------|----------|------|
| L0 | 只读建议 | 仅说明/返回静态提示，不取数不执行 | 不必 |
| L1 | 只读工具执行 | 按输入调用只读工具返回**真实数据**（取数/检查/统计） | 不必 |
| L2 | 写草稿/开单 | 可创建草稿/建议单（如待决策动作、改善单草稿），**不直接改正式数据** | 需确认 |
| L3 | 白名单写入/自动修复 | 在 Guard 白名单内**直接修改正式数据**（auto_fix、分配编号、关 INFO 债） | 高风险需审 |
| L4 | 自主多步编排 | LLM 规划 → **多工具多步** → 自主决策（在 Guard 下）→ 产出 Result + Evidence → 可回滚升级 | 重大决策仍需人审 |

## 三、L4 差距（根因）

1. **无大模型规划**：当前为规则式（if/switch）路由，非 LLM 任务规划，无法解析自由意图并规划多步。
2. **无多工具编排**：仅单工具直调，无"规划→调用A→依据结果调用B→汇总"的编排链路。
3. **无自主决策/Guard 引擎**：未接入 Guard 白名单与自主决策审批（AEOS G5 要求）。
4. **无 Result/Evidence 闭环**：动作仅到 PROPOSED，未形成 Result→Verify→Evidence 的完整闭环。
5. **无回滚/升级路径**：缺少自主执行后的回滚与升级机制。

## 四、达标 L4 所需（建议）

| 项 | 动作 |
|----|------|
| LLM | 接入本地/云大模型（配置 API Key），用于任务规划与叙述 |
| 编排 | 引入 Tool Registry + 多步 Planner（Agent Orchestrator） |
| Guard | 接入 M01 Guard：白名单工具、双人复核、重大决策强制人审 |
| 闭环 | Action → Result → Verify → Evidence 全链落库（复用 plm_improve_* / plm_agent_*） |
| 审计 | agent_tool_call / action / feedback 全审计（已有表，需串联） |
