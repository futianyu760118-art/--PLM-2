# 操作说明书（能力 B · 资料分类订阅与报告推送）

面向对象：各部门资料员、研发/品质/销售等需要「按自己的口径分类资料」并「定期收到汇总报告」的人
适用版本：恒剑光电 PLM V4.0
日期：2026-10-14

> 本说明书与系统实现逐条对应，可按步骤直接照做。文中按钮名与界面完全一致；标「仅…可见」的按钮取决于你的角色权限，看不到属正常。
> 能力 B 建立在能力 A（证据台账）之上：**资料汇总处与证据台账是同一份数据的两个视图**，所以本说明书里看到的数据，就是台账里的数据。

---

## 1. 入口在哪

登录后左侧菜单出现 **订阅与报告**（图标为标签），展开有三个子页：

| 子页 | 地址 | 用途 |
|---|---|---|
| 分类管理 | `/subscription/category` | 建本部门的分类维度与分类值（如 产品线 / 阶段 / 客户） |
| 我的订阅 | `/subscription/list` | 新建订阅、看下次生成时间、暂停/恢复/删除 |
| 我的报告 | `/subscription/report` | 看已生成的报告、正文、下载 Excel 明细 |

另有一条强相关入口在能力 A 的菜单下：

| 子页 | 地址 | 与能力 B 的关系 |
|---|---|---|
| 资料汇总处 | `/ledger/repository` | 按分类维度检索资料；在详情里给资料**打标签**、**订阅本条** |

若看不到「订阅与报告」整个菜单，说明你的角色未获 `subscription` 权限，请联系系统管理员开通。分类管理的「新建维度 / 编辑 / 删除」还需额外的部门分类管理权限。

每个页面右上角有 **操作指引** 按钮，可随时展开要点，无需离开页面。

## 2. 建分类维度（一次性准备工作）

分类维度就是你们部门「对资料分类的口径」。**先建维度，再建维度下的值。**

### 步骤

1. 进入 **分类管理**。
2. 点左上角 **新建维度**（第一次使用时列表是空的，显示「本部门还没有分类维度」，可点 **新建第一个维度**）。
3. 在弹出的 **新建分类维度** 窗口中填写：

   - **维度名称**（必填，最多 20 字）——如 `产品线`、`阶段`、`客户`。占位提示「如 产品线 / 阶段 / 客户」。
   - **共享给他部门** ——打开后，别的部门在打标签与筛选时也能选到本维度。
   - **排序** ——数字，越小越靠前。
   - **分类值** ——新建时可一次填多行（每行最多 30 字），点 **添加一行** 继续加，点行尾 **删除** 去掉多余行。

4. 点 **保存**。

### 在已有维度下加值 / 改名 / 停用

在列表中**点维度行左侧箭头展开**，里面是该维度的分类值子表：

| 操作 | 怎么做 | 说明 |
|---|---|---|
| 加值 | 点子表上方的 **新增分类值** | 窗口里「所属维度」已自动带出，填「分类值」与「排序」后 **保存** |
| 改名 | 子表行内 **改名** | 改名后所有已打该标签的资料同步显示新名字 |
| 停用 / 启用 | 子表行内 **停用** / **启用** | 停用后**历史标签保留**，但新打标签时选不到 |
| 改维度 | 主表行内 **编辑** | 可改维度名称、共享开关、排序（分类值请用子表的加值/改名） |
| 删维度 | 主表行内 **删除** | 见下方「怎么删才安全」 |

列表列含义：**维度名称 / 来源 / 分类值（个数）/ 已用于资料（条数）/ 状态 / 操作**。
「来源」列有三种标签：`本部门`（自己建的）、`已共享`（本部门建的且已共享出去）、`全局（只读）`（管理员建的，所有人可见，你只能选用不能改）。

### 怎么删才安全

点 **删除** 时系统会**先查这个维度被多少条资料使用**，然后弹确认框：

- 被 N 条资料使用过：提示「维度「xxx」已被 N 条资料使用，删除后这些资料的该维度标签将被移除，且不可恢复。确定删除？」
- 没被用过：提示「删除维度「xxx」及其全部分类值，不可恢复。确定删除？」

点 **确认删除** 才真正删除。**删之前先看清影响条数。**

> 更稳的做法是**停用而不是删除**：停用后历史标签都还在，只是不能再新打。

### 边界

- 每个部门最多 **10 个** 维度。
- 每个维度最多 **50 个** 分类值。
- 维度名称最多 **20 字**，分类值最多 **30 字**。

## 3. 给资料打分类标签

在 **资料汇总处**（`/ledger/repository`）做。

1. 用筛选条件找到那条资料（见第 6 节）。
2. 点行内 **查看** 打开右侧详情抽屉。
3. 找到「**分类标签**」分区，点旁边的 **打标签**。
4. 弹出的 **打分类标签** 窗口里，**每个维度一行**，各自一个下拉框：

   - 一个维度**只能选一个值**（下拉里选中的就是该维度当前的值）。
   - 不想设置的维度保持「不设置」占位（可点下拉的清除按钮清空）。

5. 点 **保存**。

保存后详情「分类标签」区立即显示新标签；列表里的「分类标签」列同步更新。

### 注意

- 一条资料在一个维度上**只存一个值**。同一个维度重复提交会被拒绝并提示「同一维度只能写一个分类值」。
- 一次可以给多个维度一起打标签（窗口里每个维度一行）。
- 可以一个标签都不打，资料照常存在，只是按分类筛选时命不中它。
- **打标签不会产生变更通知**，也不改变资料本身的内容与版本——分类是「检索口径」，不是资料内容。
- 如果窗口里提示「本部门暂无可用的分类维度」，说明管理员还没建维度，回到第 2 节。

## 4. 订阅：单条资料

想要「**某一条资料一有变更就告诉我**」时用这种方式。

### 方法一：在资料详情里一键订阅（最快）

1. 资料汇总处 → 找到那条资料 → **查看** 打开详情。
2. 拉到详情最下面「**订阅**」分区。
3. 点 **订阅本条变更**。订阅成功后这里变成绿色标签「已订阅 SUB-…」，旁边出现 **退订**。

> 「订阅」区下方有一行小字提示：**订阅后本条的变更会在 5 分钟内推送给你**。这是**聚合窗口**——同一条资料 5 分钟内的多次改动会合并成一条通知，不会刷屏。

### 方法二：在「我的订阅」里新建

1. 进入 **我的订阅**，点 **新建订阅**。
2. **订阅类型** 选 **单条（某条资料的变更）**。
3. **订阅名称** 可留空——占位提示「留空则取资料名称」，留空时系统用资料的名称作为订阅名称。
4. **订阅资料**（必填）：在「输入名称/编号搜索资料」的远程下拉里搜索并选中那条资料，选项显示为「编号 名称」。
5. 点 **保存**。

### 退订

- 详情里的 **退订**；或
- **我的订阅** 列表里找到那条，点 **删除**。

## 5. 订阅：周期报告

想要「**按时间定期收到一份汇总报告**」时用这种方式。

1. 进入 **我的订阅**，点 **新建订阅**。
2. **订阅类型** 选 **周期（按时间的汇总报告）**。
3. **订阅名称**：建议起个好认的名字，占位提示「如 每周试验报告汇总」。
4. **生成周期**（必填）三选一：

   | 选项 | 含义 |
   |---|---|
   | 按日（每天一份，覆盖前一天） | 每天一份，内容为**昨天**的变更 |
   | 按周（每周一份，覆盖上一周） | 每周一份，内容为**上一周**的变更 |
   | 按月（每月一份，覆盖上一月） | 每月一份，内容为**上一月**的变更 |

   > 报告覆盖的永远是**上一个完整周期**，不是你按下保存之后的时间段。刚创建当天不会立刻有一份。

5. 选「按周」时多出一个 **星期几**（周一…周日）；选「按月」时多出一个 **每月几号**（可选 **1–28** 号，避免月末对不齐）。
6. **推送时点**：选择每天几点生成并推送，默认 **08:00**。
7. **资料范围**（可选）：**每个分类维度一个多选框**，圈定这份报告只统计哪些资料。

   - 默认「全部」，即本部门资料不按分类过滤。
   - **同一个维度里选多个值是「或」**（命中任一即可）。
   - **不同维度之间是「与」**（每个维度都要命中）。
   - 例：产品线选「吸顶灯 + 吊灯」、阶段选「试产」，得到的是「（吸顶灯 或 吊灯）且 阶段=试产」的变更。
   - 如果这一行显示「本部门暂无可用的分类维度」，说明还没建维度，回到第 2 节。
8. 点 **保存**。

### 管理已有订阅

**我的订阅** 列表列：**订阅编号 / 类型 / 订阅名称 / 订阅对象 或 范围 / 周期 / 推送时点 / 下次生成 / 状态 / 操作**。

- 顶部可按 **全部 / 单条 / 周期** 过滤，右边按 **全部状态 / 启用 / 暂停** 过滤。
- 行内操作：**编辑**、**暂停**（启用状态下显示）/ **恢复**（暂停状态下显示）、**删除**。
- 编辑窗口底部多一个 **状态**（启用/暂停）单选，可在这里改；订阅类型保存后不可改。
- **「下次生成」列**告诉你这份报告下一次什么时候跑，创建后可以先看一眼确认时间对不对。
- **暂停**后不再生成新的报告，**已生成的历史报告不受影响**。
- 列表为空时显示「还没有订阅」，可直接点里面的 **新建订阅**。

### 边界

- 每人最多 **20 条** 周期订阅，超出需要先清理。

## 6. 在资料汇总处查询与下载

**资料汇总处** 是能力 B 的检索主界面，也是报告里链接的落点。

### 组合筛选（各条件之间是「并且」）

| 筛选项 | 说明 |
|---|---|
| 关键字 | 同时匹配 名称 / 编号 / 备注 |
| 证据类型 | 下拉选择 |
| 来源证据编号 | 输入 `EV-…` |
| 责任人 | 人员搜索下拉 |
| 来源部门 | 部门下拉 |
| 状态 | 草稿 / 已提交 / 已归档 / 作废 |
| 关联对象 | 先选类型，再填「编号/名称」 |
| 上传时间 | 起止区间 |
| 变更时间 | 起止区间 |

### 按分类维度筛选

筛选区下方**每个可用维度一行**，标签就是维度名（如 `产品线`），一行一个**多选框**（可多选、可清空）：

- **同一个维度多选 = 或**：产品线选「吸顶灯、吊灯」，出的是这两类的资料。
- **跨维度 = 与**：产品线选了 + 阶段也选了，要两个维度都命中。
- 点右边的 **清空分类条件** 一次清掉所有分类选择。

> 选完分类条件会自动查询，不用再点「查询」。

### 查询与查看

- 设置好条件点 **查询**；点 **重置** 清空。
- 列表上方显示「共 N 条资料；展开行按需加载该条资料下的附件清单」，右侧显示允许的附件格式与单文件大小上限。
- **展开行**（点行首箭头）：按需加载该条资料下的附件清单，列 **资料名称 / 大小 / 上传人 / 上传时间**，每行有 **预览** / **下载**。
- 没有任何匹配时显示「无匹配数据」。

### 详情里能做什么

点行内 **查看** 打开右侧抽屉，自上而下：

1. **基本信息**：资料名称、资料类型、状态、责任人、来源部门、发生时间、版本、上传时间、变更时间、备注。
2. **分类标签**：已打的标签 + **打标签** 按钮（见第 3 节）。（还没打标签时显示「暂无分类标签」）
3. **资料附件**：附件名称 / 大小 / 操作（**预览** / **下载**）。点 **预览** 时——图片和 PDF 直接在窗口里看；其他格式提示「该格式暂不支持在线预览，请下载查看」。没有附件时显示「该资料暂无附件」。
4. **关联对象**：类型 / 编号 / 名称 / 状态 / **前往**。对象被删或作废时状态列标红「失效(已作废)」或「失效(已删除)」。点 **前往** 跳到对应模块。
5. **订阅**：**订阅本条变更** / 已订阅时显示 **退订**（见第 4 节）。

### 下载

- **单个附件**：附件行的 **下载**。
- **报告明细（Excel）**：在 **我的报告** 里下（见第 7 节）。

## 7. 看报告、看正文、下 Excel

进入 **我的报告**。

### 列表

顶部可按 **全部 / 单条 / 周期** 过滤，点 **刷新** 重新拉取。
列：**报告编号 / 订阅名称 / 类型 / 覆盖周期 / 资料条数 / 状态 / 生成时间 / 操作**。

- 「覆盖周期」显示这份报告统计的是哪一段时间。
- 「资料条数」是本期命中的资料数量。
- 列表为空时显示「还没有报告；订阅命中后会自动生成」。

行内操作三个按钮：

| 按钮 | 作用 |
|---|---|
| **查看** | 打开右侧详情抽屉 |
| **正文** | 弹出 HTML 版报告正文（适合直接看或整篇复制） |
| **下载 Excel** | 导出本期明细为 xlsx，浏览器开始下载后提示「已开始下载」；无明细时按钮置灰 |

### 详情抽屉

上半部分是报告信息：**订阅名称 / 报告类型 / 状态 / 覆盖周期 / 生成时间 / 推送时间 / 失败原因**（生成失败时才有内容）。抽屉底部两个按钮：**下载 Excel 明细**、**查看 HTML 正文**。

下半部分两张表：

**本期明细**（报告里的每一条资料）

| 列 | 说明 |
|---|---|
| 来源证据编号 | **可点**——点它跳回资料汇总处并定位到这一条 |
| 资料名称 | **可点**——同上 |
| 分类标签 | 该条资料的分类标签 |
| 变更时间 | 本条在本期内发生变更的时间 |
| 操作 | **下载**——该条资料的附件（没有附件时置灰） |

> 报告里的链接就落在这里：点标题会跳到 `/ledger/repository?ledgerId=…`，**汇总处会自动定位并高亮**对应那条资料（AC-B5-2 / AC-B6-6）。

**投递记录**（这份报告被推到了哪些渠道）

列：**渠道 / 结果 / 送达对象 / 说明 / 时间**。

- 渠道分**站内**与**邮件**。
- 邮件渠道未配置时结果为「**已跳过**」——这**不影响**你在站内查看报告。
- 「失败原因」列有值时，说明该渠道投递失败，可按说明排查。

### 保留多久

报告只保留**最近 12 期**，更早的会被自动清理。要留存请及时 **下载 Excel**。

## 8. 常见问题

**Q：菜单里没有「订阅与报告」。**
A：你的角色没有 `subscription` 权限。联系管理员为角色添加该权限。

**Q：直接输网址 `/subscription/report` 进不去，提示「无权访问该页面」。**
A：这是正常的越权拦截。请从左侧菜单进入，或申请权限。

**Q：在「分类管理」看不到「新建维度 / 编辑 / 删除」。**
A：这些按钮需要部门分类管理权限。只有 `subscription` 权限时，你仍可查看本部门分类、给资料打标签、用分类筛选。

**Q：想看别的部门建的维度，怎么看不到？**
A：只有对方把维度「共享给他部门」，或管理员建的是「全局」维度，你才能选到。全局维度显示为「全局（只读）」，你只能选用不能改。

**Q：同一维度选了两个值，保存时被拒。**
A：一条资料在一个维度上只存一个值，提示「同一维度只能写一个分类值」。请把这个维度改成一个值，或在**不同**维度上打不同的值。

**Q：给资料打了标签，订阅方怎么没收到通知？**
A：设计如此。分类标签只用于**筛选与订阅命中**，不产生变更通知，也不改资料内容与版本。

**Q：删维度提示「已被 N 条资料使用」。**
A：删了会把这 N 条资料的该维度标签一并移除且不可恢复。若只是想停用，请用子表里的 **停用**。

**Q：新建周期订阅后，今天没收到报告。**
A：正常。周期报告覆盖的是**上一个完整周期**（昨天 / 上周 / 上月），不是从你保存的那一刻起算。可以看列表里的「下次生成」确认。

**Q：能不能把「按周」的订阅改成「按月」？**
A：订阅类型保存后不可修改。请删除后重新新建一条。

**Q：订阅的推送时点是不是必须写 08:00？**
A：不是，08:00 只是表单默认值，可以改成你们部门习惯的时点。

**Q：给资料打标签会不会把资料内容改了？**
A：不会。分类标签是独立数据，不改资料内容与版本，也不影响证据台账的其它字段。

**Q：报告里某条资料点进去，汇总处没定位到？**
A：链接带的是 `ledgerId`，汇总处会自动定位并高亮。若该条已超出你可见范围（非本部门且非你上传），定位不到属正常——这是权限范围内的正常表现。

**Q：报告状态为什么会有「失败」？**
A：生成阶段出错时报告会记为失败，详情里的「失败原因」写明了原因。系统会按配置自动重试。

**Q：邮件渠道一直是「已跳过」。**
A：说明管理员还没配置 SMTP 发信。这**不影响站内**的「查看 / 正文 / 下载 Excel」，等配置好后会自动开始发信。

**Q：Excel 下载按钮是灰的。**
A：本期没有可导出的明细时按钮置灰。Excel 是按需从报告内容即时生成的，不预先落盘。

**Q：刚存的草稿怎么没进报告？**
A：设计如此。**草稿不进报告**——草稿还没提交，对订阅人不构成「资料更新」。提交后就会正常计入。

**Q：报告能看多久以前的？**
A：最近 **12 期**，更早的自动清理。需要留存请下载 Excel。

**Q：每人能建多少条周期订阅？**
A：**20 条**。达到上限会拦下，请先删除不用的。

**Q：在「资料汇总处」改了东西，为什么「证据台账录入」里也变了？**
A：两者是**同一份数据的两个视图**，不是两份数据。任一侧的改动另一侧立即一致，不需要任何「同步」操作。

## 10. 术语对照（界面词 → 含义）

| 界面词 | 含义 |
|---|---|
| 分类维度 / 维度 | 一套分类口径，如「产品线」 |
| 分类值 | 维度下的具体取值，如「吸顶灯」 |
| 分类标签 | 某条资料在某维度上选定的值 |
| 单条订阅 | 盯住某一条资料的变更 |
| 周期订阅 | 按日/周/月定期收到一份汇总报告 |
| 资料范围 | 周期订阅里按分类维度圈定的统计范围 |
| 覆盖周期 | 这份报告统计的时间段（上一个完整周期） |
| 正文 | 报告的 HTML 版本，可在窗口内直接看 |
| 投递记录 | 报告推到各渠道（站内/邮件）的结果明细 |
| 资料汇总处 | 按资料维度检索、打标签、订阅、下载的页面（与证据台账同源） |
