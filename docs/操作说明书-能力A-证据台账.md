# 操作说明书（能力 A · 证据台账）

面向对象：研发工程师、品质、销售及台账管理员
适用版本：恒剑光电 PLM V4.0
日期：2026-10-14

> 本说明书与系统实现逐条对应，可按步骤直接操作。凡标注「仅…可见」的按钮，取决于你的角色权限；看不到属正常。

---

## 1. 入口在哪

登录后左侧菜单出现 **证据台账**（图标为文档），展开有三个子页：

| 子页 | 地址 | 用途 |
|---|---|---|
| 证据台账录入 | `/ledger/list` | 录入、检索、编辑证据（主要工作页） |
| 资料汇总处 | `/ledger/repository` | 只看资料与附件，展开行可直接看附件清单 |
| 变更通知 | `/ledger/notification` | 收变更通知、设置通知开关 |

若看不到「证据台账」整个菜单，说明你的角色未获授权，请联系系统管理员开通。

每个页面右上角有 **操作指引** 按钮，可随时展开要点，无需离开页面。

---

## 2. 录入一条证据（最常用）

这是能力 A 的核心操作：**所有动作都在同一个弹窗里完成，不需要跳转页面。**

### 步骤

1. 进入 **证据台账录入**，点击左上角 **新建证据**。
2. 弹窗分三块，自上而下填写：

   **① 信息**
   - 证据名称（最多 100 字）
   - 证据类型（下拉选择，如检验报告、图纸、试验数据…）
   - 责任人（输入姓名/账号搜索选择）
   - 来源部门（部门树选择）
   - 发生时间（日期选择器，**不能选未来日期**）
   - 版本（可选，最多 20 字）
   - 备注（可选，最多 500 字）

   证据编号与上传时间是系统生成的，显示为灰色只读，新建时为空属正常。

   **② 附件**
   - 点击上传区选择文件，或用 **批量上传** 一次拖入多个。
   - 单条证据最多 **20 个** 附件，单个文件不超过 **200MB**。
   - 允许的格式：pdf、doc、docx、xls、xlsx、ppt、pptx、jpg、jpeg、png、zip、rar、dwg、dxf。
   - 文件选中后会即时校验，不合格的文件会被拒绝并提示原因。

   **③ 关联对象**
   - 点击 **添加关联**，选择对象类型（项目 / 需求 / 零件物料 / BOM / 变更单 / 任务 / 评审），再搜索并选中具体对象。
   - 一条证据至少关联 **1 个**、最多 **20 个** 对象。

3. 点击 **提交**。

   提交前系统会一次性检查所有必填项，若缺失会提示「请补全必填项：xxx、yyy」，补齐后再提交即可。

4. 提交成功后弹窗关闭，新记录出现在列表顶部，状态为 **已提交**。

### 只想先存个草稿？

点弹窗底部的 **存为草稿**。草稿**不检查必填项**（仅检查长度、格式、类型和责任人/部门是否存在），可以只填名称先存下，之后再打开补充完整后提交。草稿在列表中状态显示为 **草稿**，其他人依然能看到，请勿把未完成的草稿当作正式证据使用。

## 3. 批量上传（一次传多个文件）

如果一次拿到整套资料（例如一次检验的 5 个附件）：

1. 工具栏点击 **批量上传**。
2. 一次选择多个文件（合计不超过 20 个），填写共用的信息与关联对象。
3. 提交后系统把它们**合并为 1 条证据**（多附件），而不是生成多条记录。

> 如果你要的是「一个文件一条证据」，请改用「新建证据」逐条录入。

---

## 4. 检索与筛选

列表顶部筛选区支持组合使用，各条件之间是「并且」的关系：

| 筛选项 | 说明 |
|---|---|
| 关键字 | 同时匹配 证据名称 / 证据编号 / 备注 |
| 证据类型 | 下拉选择 |
| 责任人 | 人员搜索 |
| 来源部门 | 部门树 |
| 状态 | 草稿 / 已提交 / 已归档 / 作废 |
| 关联对象 | 先选类型，再填对象编号 |
| 发生时间 | 起止区间 |
| 上传时间 | 起止区间 |

- 设置好条件点 **查询**；点 **重置** 清空。
- 起止时间若填反了，会提示「**起始时间不能大于结束时间**」，调整后重试。
- 列表底部显示总条数，每页可选 20 / 50 / 100 条。
- 没有任何匹配记录时，列表显示「**无匹配数据**」。

## 5. 查看、编辑、删除

- **详情**：点行内「详情」打开右侧抽屉，含三个页签：
  - **附件资料** —— 可下载、可在线预览（图片/PDF 直接看）。
  - **关联对象** —— 显示关联对象的类型、名称、编号，点「前往」跳到该模块；若对象已被删除或作废，会标红显示 **已作废 / 已删除** 及原因，不影响其他内容阅读。
  - **变更轨迹** —— 按时间倒序显示这条证据的全部变更记录（谁、什么时候、改了什么），可追溯到最初。
- **编辑**（仅授权角色可见）：修改信息后可 **保存** 或 **另存草稿**。
  - 编辑时**新增附件是追加**，不会覆盖原有附件；要替换请先在附件列表里「移除」再上传。
  - 若你只是想去掉一个附件而不改其他内容，保存后台账记录不会消失。
- **删除**（仅授权角色可见）：删除后列表中不再显示。
- 台账列表与资料汇总处是**同一份数据的两个视图**，一处改动，另一处立即一致，不需要任何「同步」操作。

---

## 6. 关联对象怎么管

- 在详情「关联对象」页签点 **添加关联** 增加；点某行 **解除关联** 去掉。
- 一条证据**至少保留 1 个关联对象**，尝试把最后一个解除掉会被拦下并提示「至少保留 1 个关联对象」。
- 上限 **20 个**，达到上限后「添加关联」会被拦截。
- 解除关联只断开关系，**证据本身和附件都保留**，台账记录不受影响。

### 批量关联

把已有的多条证据一次性挂到同一个对象上：

1. 在列表中勾选多条证据（可跨页勾选）。
2. 工具栏点 **批量关联**，选择对象类型与编号。
3. 提交后弹出结果窗口，显示 **成功 N 条 / 失败 M 条** 及每条失败的原因（如「已达关联上限」「对象不存在」）。
4. 单次最多 **100 条**，超出请分批处理。

## 7. 在业务模块里直接看/传证据

不必每次都进台账页 —— 相关模块里已经嵌了「关联证据」区：

| 你在哪 | 怎么看 | 怎么直接传 |
|---|---|---|
| 研发项目 · 阶段门抽屉 | 抽屉底部「关联证据」列表 | 点「录入证据」 |
| 问题与洞察 · 详情抽屉 | 抽屉底部「关联证据资料」 | 点「录入证据」 |
| 物料主数据 · 详情 | 「关联证据」页签 | 点「录入证据」 |
| 多级 BOM · 列表 | 行内「证据」按钮 → 抽屉 | 点「录入证据」 |
| 工程变更 · ECN 详情抽屉 | 抽屉底部「关联证据」 | 点「录入证据」 |
| 工作台 · 我的待办 | 行内「证据」按钮 → 抽屉 | 点「录入证据」 |

- 在这里看到的是**实时数据**：别人刚在台账页提交的证据，刷新即可见（1 分钟内保证）。
- 点「录入证据」会带着当前对象的关联信息打开台账录入弹窗（地址栏会变成 `/ledger/list?objectType=…&objectId=…`），填完提交后**自动挂到当前对象上**，不用再手动选关联。
- 「录入证据」按钮仅对有录入权限的角色显示。
- 从台账点「前往」跳回模块时，模块列表会**自动带上该对象的编号作为关键字**筛选（BOM 除外，见第 10 节）。

## 8. 模块侧改了证据信息会怎样

在模块里对已关联证据的可编辑字段（名称、类型、责任人、发生时间、版本、来源部门、状态、备注）做了修改并保存后：

- 台账侧的这些字段会**同步更新**，无需任何手工操作。
- 台账的「最后修改人 / 最后修改时间」会变成**模块侧操作人及其操作时间**，便于追责。
- 如果同一时间段内两侧都改了同一条（默认 5 分钟内），**后保存的一方生效**，并且被覆盖的一方会收到一条通知说明。

## 9. 变更通知

### 收到什么

默认你会收到这几类，通知内容包含：变更的证据、改了哪些字段、**修改前 / 修改后**的值、操作人、时间，以及一个可点击的链接（点「前往查看」直接跳到对应位置）。

| 类型 | 什么时候发 |
|---|---|
| 证据新增 | 有人新建了与你相关的证据 |
| 证据修改 | 关联的证据信息被改动 |
| 证据删除 | 关联的证据被删除 |
| 关联变化 | 证据与对象的关联被新增/解除 |
| 关联对象失效 | 你关联的对象被删除或作废 |

### 去哪看

**变更通知** 页 →「我的通知」页签：

- 未读数量显示在页签上；点 **全部已读** 一键清理。
- 点某条通知打开右侧详情，可见字段级的修改前后值；点 **前往查看** 跳到对应模块（跳过去会自动按该对象编号筛选）。
- 短时间内的多次改动会被**合并成 1 条**通知（默认 5 分钟窗口），展开可见每一次变更明细，避免刷屏。

### 关掉不想要的

**变更通知** 页 →「通知设置」页签，五种类型各自一个开关，**互不影响**。关闭某类后不再收到该类通知，其余照常。未设置过的一律视为开启。

## 10. 常见问题

**Q：菜单里没有「证据台账」。**
A：你的角色没有 `ledger` 权限。请联系管理员为你的角色添加台账权限。

**Q：直接输网址 `/ledger/list` 进不去，提示「无权访问该页面」。**
A：这是正常的越权拦截。请从左侧菜单进入，或申请权限。

**Q：我只有查看权，看不到「新建/编辑/删除」。**
A：按角色区分：查看角色只显示「详情」和「下载」；编辑角色没有「删除」；台账管理员拥有全部操作。

**Q：提交时提示「至少上传 1 个附件」。**
A：正式提交（非草稿）必须带附件。若手头还没有材料，先 **存为草稿**，拿到附件后再打开编辑并提交。

**Q：选了明天的日期，提交不了。**
A：「发生时间」不允许晚于当前日期，这是硬性校验。请修正日期。

**Q：上传提示「不支持的附件格式」。**
A：只接受 pdf/doc/docx/xls/xlsx/ppt/pptx/jpg/jpeg/png/zip/rar/dwg/dxf 十四种。其他格式请联系管理员在配置中追加白名单。

**Q：文件传不上去，提示超限。**
A：单个文件上限 200MB、单条证据附件上限 20 个（等于上限可以通过，超出即拒绝）。大文件请压缩或拆分。

**Q：一条证据最多能关联几个对象？**
A：20 个。批量关联一次最多处理 100 条证据。

**Q：想解除最后一个关联对象，不让解。**
A：正式证据必须至少保留 1 个关联对象。要彻底废弃请改用「删除」或把状态置为「作废」。

**Q：从台账点 BOM 的「前往」，列表没有按 BOM 编号筛出来。**
A：BOM 列表当前只支持按顶级料号与状态过滤，所以这一处不带关键字预置，需要你在 BOM 页自行输入编号。其余模块（项目、需求、物料、变更单、复盘）都会自动带上关键字。

**Q：关联对象那一行标红了「已作废 / 已删除」怎么办？**
A：说明被关联的对象已经被删除或作废。关联关系会保留并标注原因，不会报错、也不会被静默丢弃。如需继续使用这条证据，可解除该关联并另挂到有效对象上。

**Q：编辑时新传了附件，原来的附件没了？**
A：不会。编辑时新增附件是**追加**语义，原附件保留。要替换请先「移除」再「追加」。

**Q：两侧同时改同一条证据会怎样？**
A：以**后保存**的一方为准；被覆盖的一方会收到通知提示其改动已被覆盖，请以最新值为准。

**Q：谁改过这条证据，能查吗？**
A：打开详情 →「变更轨迹」页签，按证据编号完整列出每次改动（操作人、时间、变更字段、前后值），日志只读、不可修改，保留 3 年以上。

**Q：「证据台账录入」和「资料汇总处」是什么关系？**
A：同一份数据的两个视图。录入页便于维护，汇总处便于按资料维度翻查附件（展开行即可看附件清单）。任一侧的改动另一侧立即一致，不存在两份数据。

## 11. 边界与限制速查

| 项目 | 上限 |
|---|---|
| 单条证据附件数 | 20 个 |
| 单个附件大小 | 200MB |
| 附件格式 | 14 种（见第 2 节） |
| 单条证据关联对象 | 20 个（正式提交至少 1 个） |
| 批量关联 | 一次 100 条证据 |
| 批量上传 | 一次 20 个文件，合并为 1 条证据 |
| 证据名称 / 备注 / 版本 | 100 / 500 / 20 字 |
| 发生时间 | 不得晚于当前日期 |
| 通知聚合窗口 | 5 分钟 |
| 操作日志保留 | 3 年（1095 天） |
