# EBMS × PLM 打通总规 — 管理跟进视角与分工设计

> 文档编号: HJ-EBMS-PLM-MP-20260722  
> 范围:  
> - **EBMS** 企业经营管理平台 `:3010`（`sales-service-system`）  
> - **PLM** 研发/工程中台（`PLM-2` + 合并后的 V5 架构，含 `:3000` 三维能力）  
> 焦点页: `http://localhost:3010/order-analysis.html`（订单分析库）与研发中心全模块

---

## 1. 定位：两个系统，一个经营闭环

| 系统 | 本质 | 管理语言 | 核心问题 |
|------|------|----------|----------|
| **EBMS** | 企业经营与交付管理系统 | 钱、单、人、期、利 | 接什么单？赚不赚钱？交不交得出？谁卡住？ |
| **PLM** | 产品工程与技术真相源 | 料号、版本、图纸、BOM、变更 | 做成什么样？改了什么？能不能量产？资料受控否？ |

**原则（必须写进制度）：**

1. **经营真相在 EBMS，工程真相在 PLM** — 禁止双写主数据互相覆盖。  
2. **PartNo（产品/物料编码）是唯一跨系统主键**；订单号、项目号是业务主键。  
3. **EBMS 管“跟进与决策”，PLM 管“设计与受控”**；界面可互跳，数据经集成总线同步。  
4. **订单分析库是经营侧驾驶舱入口之一**，不是第二套 PLM。

```
客户/市场 ──► EBMS销售 ──► 询价/报价/样品/订单
                 │                    │
                 │ 立项/需求           │ 订单映射产品
                 ▼                    ▼
              EBMS研发项目  ◄──同步──►  PLM 产品/物料/BOM/图纸/ECN
                 │                    │
                 │ 技转/进度/风险       │ 发布/变更/版本
                 ▼                    ▼
         订单分析库(计划成本/审核/毛利) ◄── 正式BOM成本价
                 │
                 ▼
         采购/领料/人工/费用 ──► 实际成本 ──► 经营复盘/阿米巴
```

## 2. EBMS 现状画像（管理视角）

### 2.1 九大中心（菜单事实）

| 中心 | 代表模块 | 管理目的 |
|------|----------|----------|
| 首页 | 仪表盘 | 全局待办与穿透 |
| **经营中心** | 年度计划、阿米巴、费用、人工、**订单分析库**、领料单、AI | 算清账、控风险、跟目标 |
| **销售中心** | 客户、询价、报价、订单、样品、反馈 | 拿单与客户经营 |
| **研发中心** | 产品、项目、配置表、BOM、BOM对比、技转、规格书 | 项目交付与技术资料（偏管理台） |
| 供应链 | 物料库、供应商、采购 | 价与供 |
| 生产/品质/报表/系统 | … | 支撑闭环 |

### 2.2 订单分析库（:3010/order-analysis.html）— 经营心脏

后端自述四大能力（`order-analysis.js`）：

| # | 能力 | 管理含义 | 数据依赖 |
|---|------|----------|----------|
| 1 | **订单审核** pending→通过/驳回 | 经营审批：接单是否划算 | review_logs |
| 2 | **计划成本** BOM×物料库单价（料/工/费） | 接单前算毛利 | bom_items + materials |
| 3 | **同类比对** 产品/客户/BOM 相似度 | 历史经验辅助决策 | 历史订单快照 |
| 4 | **计划 vs 实际** 领料/人工/费用归集 | 超支预警、复盘 | material_issues / labor / expenses |

配套：

- **订单-产品映射** `order-product-map`：外部订单字段 → BOM 产品编码 → 自动展开分级 BOM  
- **多产品订单** `order_products`  
- **成本快照** `order_cost_snapshots`（plan/actual）

**管理痛点（当前）：**

| 痛点 | 表现 | 根因 |
|------|------|------|
| 产品未映射 | 大量订单 `product_count=0`，无法核算 | ERP 编码 ≠ BOM 编码，映射规则不全 |
| 计划成本失真 | 用 EBMS 本地 BOM/物料价 | 与 PLM 正式版 BOM/价不同步 |
| 审核缺工程门禁 | 只审钱，不审“能否做/图纸是否发布” | 未读 PLM lifecycle |
| 变更不回流 | 项目 change_count 很高，订单成本不重算 | 无 ECN→成本失效事件 |
| 跟进碎片化 | 项目进度在 project，成本在 order-analysis，图纸在 tech-transfer | 无统一“订单/项目作战室” |

### 2.3 研发中心（EBMS 内）— 管理台而非工程台

| 模块 | 管理价值 | 与 PLM 重叠风险 |
|------|----------|----------------|
| **项目管理** | 立项、阶段节点（外观/结构/模具/T1/T2/技转…）、金额、变更次数、交付跟进 | 阶段应驱动 PLM phase，不应再维护第二套图纸状态 |
| **产品管理** | 内外型号、品类经营属性 | 正式料号/版本应以 PLM 为准 |
| **BOM 管理** | 分级成本 BOM、订单汇总 | 与 PLM EBOM/MBOM 易双源；EBMS 应消费“成本视图” |
| **BOM 对比** | 基础/订单/生产 BOM 差异 + 问题单 | 工程变更差异应以 PLM ECN diff 为准；经营差异可留 EBMS |
| **产品配置表** | 客户需求结构化（壳体/光学…） | 是需求输入，应下推 PLM 设计基线 |
| **项目技转** | 资料库/流转/技术变更/审计 | 与 PLM 档案/ECN/分享高度重叠 → **必须归并边界** |
| **规格书库** | 对外规格 | PLM 发布后同步只读 |

**结论：** EBMS 研发中心适合做 **项目经营与进度跟进**；不适合做 **版本受控与 3D/图纸权威源**。

## 4. 主数据与编码对齐（打通第一前提）

### 4.1 编码体系

| 对象 | 权威系统 | 字段 | EBMS 用法 |
|------|----------|------|-----------|
| 成品/组件料号 | **PLM** | `part_no` | product_code / internal_model 对齐 |
| 物料（原材料） | PLM 为主，EBMS 可缓存价 | `part_no` / material_code | 核价、BOM 成本 |
| 订单号 | **EBMS/ERP** | `order_no` | 经营全链路 |
| 项目号 | **EBMS** 立项生成 | `project_no` | 进度与技转；写入 PLM 关联 |
| 客户编码 | EBMS/ERP | customer_code | 映射规则、权限范围 |
| ECN 号 | **PLM** | `ecn_no` | 回写项目变更、触发重算 |
| 版本 | **PLM** | `version_no` / revision | 订单锁定“接单版本” |

### 4.2 订单 → 产品映射升级

保留 EBMS `order_product_map`，增加 **PLM 校验**：

```
外部订单字段
  → 映射规则命中 product_code
  → 调用 PLM GET /parts/{partNo}
       · 必须存在且 lifecycle ∈ {RELEASED, IN_PRODUCTION}
       · 取当前 version_no、MBOM/成本BOM 引用
  → 展开计划成本（价：物料库；结构：PLM 正式 BOM）
  → 写入 order_analysis 快照（带 plm_version、bom_id）
```

未映射 / PLM 未发布 → **禁止审核通过**（可配置：仅预警 or 硬拦截）。

## 5. 端到端管理流程（跟进视角）

### 5.1 线索到量产（L2O + NPI）

```
① 客户/询价(EBMS销售)
    → 配置表/目标价(EBMS研发配置)
    → 是否新品？
         是 → 立项申请(EBMS项目) → 自动开 PLM 产品壳(DRAFT)+档案树
         否 → 选已有 PartNo(PLM RELEASED)
② 样品(EBMS sample) ↔ PLM 试制版本(TRIAL phase)
③ 报价/核价(EBMS) ← PLM 成本BOM + 物料价(EBMS物料库/采购)
④ 订单进入(EBMS) → 映射产品 → 订单分析库计划成本 → 经营审核
⑤ 项目执行节点(EBMS看板)
    ↔ PLM phase/lifecycle 节点完成（结构/模具/T1/T2/技转）
⑥ 技转放行：PLM 资料包 RELEASED + EBMS 技转流程签字
⑦ 量产：PLM IN_PRODUCTION → EBMS 可接大货；订单锁定版本
⑧ 变更：PLM ECN → 事件 → EBMS 订单/项目风险 + 成本重算待办
⑨ 交付复盘：实际成本(领料/人工/费用) vs 计划 → 阿米巴/年度计划
```

### 5.2 订单分析库 — 管理跟进工作台（升级定义）

将 `order-analysis` 定义为 **「订单经营作战室」**，五个 Tab：

| Tab | 管理者看什么 | 动作 |
|-----|--------------|------|
| 审核台 | 毛利、超支风险、映射状态、PLM 发布状态 | 通过/驳回/退回补映射 |
| 详情比对 | 分级 BOM、计划三层成本、同类单差异 | 指定产品、锁版本 |
| 多维分析 | 客户/产品/月份/风险 | 经营决策 |
| 映射治理 | 未映射清单、规则命中率 | 建规则、批量应用 |
| **工程协同**（新） | PLM 版本、未关闭 ECN、图纸/技转缺口、项目进度 | 跳转 PLM/项目；拉任务 |

**审核门禁（建议制度）：**

| 级别 | 条件 | 角色 |
|------|------|------|
| L0 系统 | 已映射 PartNo；PLM 状态允许接单；有计划成本 | 自动 |
| L1 经营 | 毛利率 ≥ 阈值；无红色超支预测 | 经营/销售负责人 |
| L2 工程 | 无阻塞 ECN；关键图纸 RELEASED；技转状态达标（大货） | 研发/工艺 |
| L3 特批 | 不满足 L1/L2 | 总经理/委员会 + 风险单 |

### 5.3 项目进度节点 ↔ PLM 阶段映射

| EBMS project.progress 节点 | PLM phase / 证据 |
|----------------------------|------------------|
| 立项 plan | CONCEPT；项目号绑定 |
| 外观 appearance | STRUCTURE；外观 3D/评审纪要 |
| 结构 structure | STRUCTURE；EBOM DRAFT→IN_REVIEW |
| BOM bom | EBOM/MBOM RELEASED |
| 规格 spec / 配置 config | 规格书/配置基线归档 |
| 模具图 mold_drawing / 评审 | MOLD_DEV；模具档案节点 |
| 手板/模具样 | TRIAL；试模履历 |
| T1/T2 / 研试/工试/产试 | TRIAL 子状态；检验标准 |
| 技转 tech_transfer | 技转包 + 文件 RELEASED |
| 出货 shipment | IN_PRODUCTION 或订单交付 |
| 复盘 review | 关闭；经验回 EBMS AI/案例 |

**跟进规则：** EBMS 节点可人工点，但 **“完成”以 PLM 证据或双方确认事件为准**（防空点）。

## 6. 集成架构（技术落地）

### 6.1 拓扑

```
┌──────────────── EBMS :3010 ────────────────┐     ┌──────── PLM V5 ────────┐
│ 经营/销售/项目跟进/成本/阿米巴/权限           │     │ 工程主数据/BOM/ECN/档案 │
│  order-analysis · project · bom(成本视图)   │◄───►│  part · bom · change   │
└───────────────────┬────────────────────────┘     └───────────┬────────────┘
                    │  Integration Bus                         │
                    │  (建议：EBMS external-sync 扩展 + PLM integration)
                    │  REST + Webhook/Outbox + 日对账
                    ▼                                          ▼
              共享：PartNo · ProjectNo · OrderNo · EcnNo · Version
```

### 6.2 接口清单（最小可用集 MVP）

| 方向 | 接口 | 用途 |
|------|------|------|
| EBMS→PLM | `POST /integration/projects` | 立项同步：开 Part 壳、绑 project_no |
| EBMS→PLM | `POST /integration/orders/{no}/link` | 订单锁定 part+version |
| PLM→EBMS | `GET /parts/{partNo}` `GET /bom/{partNo}/cost-view` | 映射校验、计划成本结构 |
| PLM→EBMS | `Webhook EcnEffective` | 变更命中料号 → 打开重算/风险 |
| PLM→EBMS | `Webhook PartStateChanged` | 发布/作废/量产 → 接单策略 |
| PLM→EBMS | `GET /packages/tech-transfer/{partNo}` | 技转包元数据+受控链接 |
| 双向 | `GET /sync/reconcile?date=` | 日对账：编码、版本、BOM 哈希 |

### 6.3 数据所有权矩阵（防扯皮）

| 数据 | 创建 | 修改 | 删除/作废 | 只读副本 |
|------|------|------|-----------|----------|
| PartNo/版本/生命周期 | PLM | PLM | PLM | EBMS |
| EBOM/工程 BOM | PLM | PLM+ECN | PLM | EBMS 成本展开 |
| 订单 BOM/客户特殊配 | EBMS | EBMS | EBMS | 可回写 PLM 变体（可选） |
| 物料采购价 | EBMS/采购 | EBMS | — | PLM 参数可引用 |
| 项目进度经营字段 | EBMS | EBMS | EBMS | PLM 关联 |
| 项目技术完成证据 | PLM | PLM | PLM | EBMS 节点 |
| 图纸/3D 文件 | PLM | PLM | 禁止物理删 | EBMS 链接 |
| 订单/毛利/审核 | EBMS | EBMS | EBMS | — |
| ECN | PLM | PLM | PLM | EBMS 项目变更计数 |

### 6.4 BOM 三源收敛策略

| 视图 | 系统 | 说明 |
|------|------|------|
| 工程 EBOM | PLM | 设计结构权威 |
| 制造 MBOM | PLM | 工艺/生产 |
| **成本 CBOM** | EBMS 生成 | PLM 结构 × EBMS 单价/费率；供 order-analysis |
| 订单 BOM | EBMS | 客户订单差异；对比问题进 bom-compare |
| 生产 BOM | EBMS/MES | 现场执行；差异问题闭环 |

**禁止：** 在 EBMS 长期手工维护与 PLM 分叉的“主 BOM”而不标注来源。

## 7. 管理跟进体系（组织 + KPI + 节奏）

### 7.1 角色分工（RACI）

| 事项 | 销售 | 经营/财务 | 项目经理 | 研发工程 | 工艺/品质 | 采购 | IT |
|------|------|-----------|----------|----------|-----------|------|-----|
| 客户与接单 | **A/R** | C | C | C | I | I | I |
| 订单映射 PartNo | C | C | **R** | **A**（编码） | I | I | C |
| 计划成本核算 | I | **A** | R | C | C | C | C |
| 订单经营审核 | C | **A/R** | C | C | I | I | I |
| 工程可制造审核 | I | I | R | **A** | **R** | I | I |
| 立项与进度 | C | C | **A/R** | R | C | C | I |
| 图纸/BOM/ECN | I | I | C | **A/R** | C | I | C |
| 技转放行 | I | I | **R** | **A** | **R** | I | I |
| 实际成本归集 | I | **A** | C | I | I | R(料) | C |
| 超支复盘 | C | **A** | **R** | C | C | C | I |
| 主数据与集成 | I | C | C | C | I | C | **A/R** |

A=Accountable 终责 · R=Responsible 执行 · C=Consulted · I=Informed

### 7.2 管理节奏

| 节奏 | 会议/机制 | 看的板 | 输出 |
|------|-----------|--------|------|
| 日 | 项目站会 15min | EBMS 项目延误节点 + PLM 阻塞 ECN | 当日动作 |
| 日 | 经营值班 | 订单分析：未映射、待审、超支红灯 | 催映射/催审 |
| 周 | 订单利润会 | 审核台 + 毛利分布 + 同类对比 | 接单策略 |
| 周 | 技转/变更会 | 技转在途 + ECN 生效清单 | 放行/冻结 |
| 月 | 经营复盘 | 计划vs实际、阿米巴、年度 KPI | 改进项 |
| 季 | 产品组合会 | 产品利润 + 生命周期 + 呆滞风险 | 作废/主推 |

### 7.3 KPI（系统可算）

| KPI | 定义 | 数据源 |
|-----|------|--------|
| 映射覆盖率 | 有 PartNo 的订单金额 / 总订单金额 | order-analysis |
| 审核及时率 | 承诺交期内完成 L1 审核比例 | review_logs |
| 计划毛利率 | median/平均 | 成本快照 |
| 毛利偏差 | (实际毛利−计划)/计划 | plan vs actual |
| 超支订单率 | has_overrun 订单占比 | order-analysis |
| 工程门禁拦截率 | L2 不通过次数（质量信号） | 集成日志 |
| 项目节点准时率 | 按期完成关键节点 | project.progress |
| ECN 闭环周期 | 提交→生效天数 | PLM |
| 版本锁定率 | 大货订单绑定 PLM version 比例 | 订单-版本表 |
| 技转一次通过率 | 无退回放行 | tech-transfer |
| BOM 同源率 | EBMS 成本 BOM 哈希 = PLM 正式版 | 对账任务 |

## 8. 模块级分工总表（谁做什么、停什么）

### 8.1 EBMS 保留并强化

- 经营中心全套（订单分析、费用、人工、领料、阿米巴、年度计划）  
- 销售中心全套  
- **项目经营台**（进度、金额、客户、风险、变更次数展示）  
- **成本 CBOM 与核价**（消费 PLM 结构）  
- **订单/项目 BOM 差异问题单**（经营与交付差异）  
- 组织权限、数据范围、外部 ERP 同步（订单/客户/库存价）

### 8.2 PLM 权威并增强

- 料号/版本/生命周期/阶段  
- 工程 BOM 三态、3D、档案、水印、外协、模具、SOP、ECN  
- 技转**受控包**生成（文件+版本清单）

### 8.3 边界归并（避免双轨）

| 现状重叠 | 决策 |
|----------|------|
| EBMS 技转资料库 vs PLM 档案 | **文件存 PLM**；EBMS 只保留流转任务、签字、审计索引 |
| EBMS 技术变更 vs PLM ECN | **变更单在 PLM**；EBMS 显示状态与影响订单/项目 |
| EBMS BOM 手工主数据 vs PLM BOM | 主结构 PLM；EBMS 同步只读 + 订单差异层 |
| EBMS 产品 vs PLM Part | 经营属性在 EBMS；工程属性在 PLM；编码统一 |
| EBMS 物料图纸 vs PLM 文件 | 新图纸进 PLM；旧数据迁移后 EBMS 转链接 |

### 8.4 订单分析库改造清单（产品需求）

1. 列表增加列：`part_no`、`plm_version`、`plm_state`、`open_ecn`、`project_no`  
2. 指定产品时调 PLM 校验发布态  
3. `calcPlanCost` 结构源切换：PLM cost-view（可回退本地 BOM）  
4. 审核流增加 L2 工程检查项  
5. 订阅 ECN 生效 → 标记「成本失效」待重算  
6. 详情页嵌入：项目进度条、PLM 链接、技转状态  
7. 未映射治理与 PLM 主数据搜索合一

## 11. 成功标准（管理层可验收）

1. **映射覆盖率 ≥ 95%**（按金额，上线 8 周内）。  
2. 大货订单 **100% 绑定 PLM 版本**；未发布料号无法审核通过。  
3. 计划成本与 PLM 正式 BOM 结构一致（对账差异 &lt; 1% 行）。  
4. ECN 生效后 **24h 内** 相关打开订单出现“待重算”。  
5. 订单分析库可一键跳转：项目进度、PLM 物料、ECN、技转包。  
6. 技转放行以 PLM 受控包为准，EBMS 可查审计。  
7. 月度经营会固定使用：审核台 + 超支榜 + 项目延误榜 + 变更榜。

## 12. 一句话总纲

> **EBMS 用订单分析库把“单”算清、审清、跟清；PLM 把“品”设计清、版本清、变更清；两边用 PartNo + 项目号 + 订单锁版本钉在一起——经营不发明工程真相，工程不脱离接单与利润约束。**
