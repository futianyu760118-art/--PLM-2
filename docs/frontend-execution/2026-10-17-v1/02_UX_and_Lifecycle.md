# 02 界面、导航与全生命周期

## 五模式页面要求
| 模式 | 导航结构 | 主页面 | 重点 |
|---|---|---|---|
| 原版业务 | 业务模块分组，保留旧入口 | 表格、查询、详情 | 保持老用户操作路径；标识为仓库结构还原 |
| 产品工作空间 | 当前产品 + 专业模块 | 概览、需求、结构电气、BOM、工作表、证据 | 围绕产品与版本聚合，不复制数据 |
| 专业视图集 | 岗位行动、工程评审、工具画布 | 三种专业视图 | 与岗位微系统清晰分工 |
| 项目协同 | 60px主轨 + 220px副轨，最多两级 | 卡片、表格、看板、截止时间线、任务抽屉 | 同一状态分组；不开放没有接口支持的拖拽 |
| Multica参考 | 低饱和分组侧栏、底部设置 | 紧凑分组列表、看板、角色工具、运行记录 | 仅借鉴交互，不代表执行引擎已集成 |

## 通用交互
- 顶部模式选择、项目入口、帮助学习与外观入口始终可找到；窄屏也不能只依赖已隐藏侧栏。
- 切换模式保留 projectId、partNo、taskId（适用时）、筛选和已保存状态。
- 原版回退入口不丢失；未保存表单先保存、自动保存草稿或提示处理。
- 正式实现使用可深链接路由；浏览器前进后退恢复模式、项目和视图。
- 目标模式没有对应页面时回到同一项目概览，明确提示并保留原功能入口。
- 空白、加载、接口失败、无权限状态分别设计，失败不能静默转换成成功或零数据。

## 生命周期展示模型
| 阶段 | 主要交付 | 当前实施口径 |
|---|---|---|
| 需求与立项 | 需求、立项、目标约束 | 关联现有立项与项目 |
| 方案与规格 | 规格、配置、方案评审 | 关联项目工作表 |
| 详细设计 | 图纸、物料、EBOM、模型 | 关联既有工程模块 |
| 样机与验证 | 样品、试验条件与结果、整改 | 不自动判断合格 |
| 试产与评审 | 试产、工艺、检验、遗留项 | 复用工作表与评审 |
| 量产移交 | 发布包、接收记录 | 发布与接收口径待联调 |
| 上市与在产维护 | 在产版本、生产与销售反馈 | 聚合规划；数据待接入 |
| 售后与质量反馈 | 反馈、失效分析、纠正措施 | 与相应系统分工，待接入 |
| 变更与迭代 | ECN、影响、验证、生效版本 | 跨多个阶段循环发生 |
| 停产评估与批准 | 订单、库存、供应、模具、服务评估 | 执行与审批待确认 |
| 产品退市 | 渠道退出、库存处置、服务安排 | 不虚构退市接口 |
| 归档与持续义务 | 归档、追溯、备件服务、经验 | 不因退市删除记录 |

这不是固定线性状态机；售后与变更可触发返工、重新验证。G0–G8 是现有工程阶段门，以后端定义为准。

## 品牌与视觉
公司名称右上；左上使用正式获批 LOGO。原型 H 标记仅为占位，不是最终品牌资产。中文使用系统可用中文无衬线，工程编号保留可读性。状态颜色与文字并用。

## 外观设置
| 设置 | 选项 | 保存与约束 |
|---|---|---|
| 强调色 | 六套预设 + 自定义 | 主要操作、选中态使用；成功/警告/异常独立 |
| 页面底色 | 八套预设 + 自定义 | 工作区底色；资料卡片保持浅色；不是全站暗色主题 |
| 侧栏 | 跟随模式、浅色、深色 | 不影响布局和权限 |
| 密度 | 舒适、紧凑 | 不缩小到不可点击或不可读 |

颜色选择与布局模式解耦。前端存储设置包含 schemaVersion，支持旧版本迁移与恢复默认；正式用户偏好是否跨设备同步另行确认，不改变当前后端。

## 响应式与无障碍
至少检查 1440×900、1280×720、768×1024、390×844、360×800 及 200% 缩放。表格可在自身容器横向滚动，页面不应出现非预期横向滚动。控件可用键盘访问；对话框有名称、焦点圈定、关闭后恢复焦点；尊重减少动态效果。普通文本对比度以 4.5:1、必要图形以 3:1 为检查目标，不能用局部色彩计算代替整页验证。
